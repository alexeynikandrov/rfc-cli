## Problem

Сейчас `rfc-cli` не показывает собственную версию: параметры `--version` и
`-V` отсутствуют, потому что версия не включена в конфигурацию `clap`.
Пользователь не может быстро проверить, какая сборка установлена.

## Goal

Добавить стандартный вывод версии через `--version` и `-V`, используя версию
пакета из `Cargo.toml`.

## Requirements

1. `rfc-cli --version` выводит имя программы и текущую версию пакета.
2. `rfc-cli -V` является коротким эквивалентом `--version`.
3. Версия берётся автоматически из `CARGO_PKG_VERSION`, без дублирования в
   исходном коде.
4. Поведение существующих команд не меняется.

## Design

В атрибут `#[command]` структуры `Cli` добавить `version`:

```rust
#[command(name = "rfc-cli", about = "Manage RFC documents", version)]
```

`clap` сгенерирует параметры `--version` и `-V` на основании
`CARGO_PKG_VERSION`.

Добавить интеграционный тест, проверяющий оба варианта и соответствие версии
пакета.

## Alternatives

1. **Добавить отдельную подкоманду `version`**  
   Не соответствует стандартному CLI-поведению и требует лишнего синтаксиса.

2. **Хранить версию отдельной константой**  
   Создаёт риск рассинхронизации с версией в `Cargo.toml`.

## Voting

Решение принято: использовать встроенную поддержку версии в `clap`.

## Migration

Миграция не требуется. Добавляется только стандартный глобальный параметр CLI.
